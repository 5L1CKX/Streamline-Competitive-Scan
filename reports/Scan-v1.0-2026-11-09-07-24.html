5. Standard UX kit (implement, don't invent)

(keep baseline list; append only where sources justify)

  1. One visible assistant; orchestrator routes to hidden specialized agents. (baseline)
  2. Context-aware quick actions on record/grid/map: "Ask", "Summarize", prefilled prompts attached to context. (baseline)
  3. Agent transparency stream: agent narrates plan, user can stop/redirect mid-run. (baseline)
  4. HITL statuses: AI fills -> per-field AI markers -> pending approval -> approve/revert. (baseline)
  5. Embedded generation next to the record, not in a separate tool. (baseline)
  6. Agent catalog + per-agent KPI/consumption metering. (baseline)
  7. Capture-time mobile validation (photo checked as taken). (baseline)
  8. Consumption pricing per agent action: simple assist cheap, multi-step xN. (baseline)

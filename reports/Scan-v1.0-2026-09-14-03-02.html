5. Standard UX kit (implement, don't invent)

Carry-forward baseline kit:

  1. One visible assistant; orchestrator routes to hidden specialized agents.
  2. Context-aware quick actions on record/grid/map: "Ask", "Summarize", prefilled prompts with context.
  3. Agent transparency stream: agent narrates plan; user can stop/redirect mid-run.
  4. HITL statuses: AI fills -> per-field "AI-filled" markers -> pending approval -> approve/revert.
  5. Embedded generation next to the record (not a separate tool).
  6. Agent catalog + per-agent KPI/consumption metering.
  7. Capture-time mobile validation (photo checked as taken).
  8. Consumption pricing per agent action: cheap assist vs multi-step expensive.

New / reinforced this run:

  • Add a governance/observability surface ("Control Tower") for discover/observe/govern/measure across agents. ✔ ["AI Control Tower" — https://news.google.com/rss/articles/CBMiqgJBVV95cUxN...]

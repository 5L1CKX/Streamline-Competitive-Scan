  • Netcracker explicitly calls out MCP and A2A support on its product page, validating the open-agent interoperability blueprint that Streamline intends to adopt.

  • For Streamline: double-down on LLM-native auto-design (lead differentiator, NOW), and copy agent-orchestrator + governance patterns (ServiceNow/Netcracker) for NEXT.
  • No vendor in these sources demonstrates an LLM-driven, conversational, map-aware fiber-design agent today; that remains our commercial white space. ○

5. Standard UX kit (implement, don't invent)

From baseline; unchanged except where sources added a confirmed pattern

  1. One visible assistant; orchestrator routes to hidden specialized agents.
  2. Context-aware quick actions on record/grid/map: "Ask", "Summarize", prefilled prompts opening a chat with context attached. ✔ “AI-enhanced search deliver instant file summaries and insights”bentley.com
  3. Agent transparency stream: agent narrates plan, user can stop/redirect mid-run.
  4. HITL statuses: AI fills -> per-field AI markers -> pending approval -> approve/revert.
  5. Embedded generation next to the record, not in a separate tool.
  6. Agent catalog + per-agent KPI/consumption metering. ✔ “Ready-to-Deploy AI Agents”netcracker.com
  7. Capture-time mobile validation (photo checked as taken). ✔ “<2 seconds to analyze a photo”iqgeo.com
  8. Consumption pricing per agent action: simple assist cheap, multi-step xN.
